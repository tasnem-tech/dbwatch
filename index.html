🛡️ DBWatch

Database Monitoring & Change Tracking System

DBWatch is a Python-based CLI tool that monitors SQL databases, detects schema and data changes, compares snapshots, and generates audit reports.

View GitHub Code See Demo

Key Features

📊 Database Monitoring

Monitor SQL database tables and track record changes over time.

📸 Snapshot Tracking

Create database snapshots for future comparison and auditing.

🔍 Change Detection

Detect inserted, updated, and deleted records between snapshots.

📄 Reporting

Generate structured reports summarising detected database changes.

⏰ Scheduled Checks

Run automated monitoring jobs using scheduling support.

💻 CLI Workflow

Use simple terminal commands to run snapshots, comparisons, and reports.

Demo Commands

# Create a database snapshot
python cli.py snapshot

# Compare two snapshots
python cli.py compare

# Generate a report
python cli.py report

# Start scheduled monitoring
python cli.py monitor
