# DBWatch

DBWatch is a Python-based database monitoring and reporting tool.

## Features
- Monitor database changes
- Generate reports
- Snapshot tracking
- Scheduler support
- CLI integration

## Project Structure

- `cli.py` → Command line interface
- `connector.py` → Database connection handling
- `snapshot.py` → Snapshot management
- `reporter.py` → Report generation
- `scheduler.py` → Scheduled monitoring
- `differ.py` → Compare database snapshots
